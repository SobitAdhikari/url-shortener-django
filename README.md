# URL Shortener (Django)

A simple URL shortener built using Django.

## Features
- Shorten long URLs
- Redirect using short links
- Click tracking

## Tech Stack
- Django
- SQLite
- Python

## to run
## migrate the models : 
     python manage.py makemigrations
     python manage.py migrate
## run the server : 
    python manage.py runserver


You are good to goo >>>
